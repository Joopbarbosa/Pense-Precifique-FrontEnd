### Variante 1 — StatusBadge (status do orçamento)

```tsx
type StatusOrcamento =
  | 'Rascunho' | 'Enviado' | 'Aprovado'
  | 'Aguardando Sinal' | 'Sinal Pago'
  | 'Em Produção' | 'Finalizado'
  | 'Entregue' | 'Pago' | 'Cancelado'

interface StatusBadgeProps {
  status: StatusOrcamento
  size?: 'sm' | 'md'  // sm = 24px, md = 28px (default)
}
```

**Cores por status (extraídas do design):**

| Status | bg | fg | dot |
|--------|----|----|-----|
| Rascunho | `#F1F0EC` | `#7C786F` | `#A8A49C` |
| Enviado | `#EAF1FB` | `#2A6FB0` | `#3A86CE` |
| Aprovado | `#EAF7EF` | `#3E9D5A` | `#54B36F` |
| Aguardando Sinal | `#FFF8EC` | `#B07A1F` | `#E0A030` |
| Sinal Pago | `#FFF1E8` | `#C8721F` | `#F97316` |
| Em Produção | `#FFF1E8` | `#C8721F` | `#F97316` |
| Finalizado | `#E7F4F1` | `#1F7A6F` | `#2A9D8F` |
| Entregue | `#E8F5EE` | `#1F8A5B` | `#34A56F` |
| Pago | `#E2F0E6` | `#176B43` | `#1F8A5B` |
| Cancelado | `#FCF0EC` | `#C0492B` | `#D06A4E` |

**Estrutura visual:**
```tsx
<span style={{
  display: 'inline-flex',
  alignItems: 'center',
  gap: 6,
  height: size === 'sm' ? 24 : 28,
  padding: size === 'sm' ? '0 9px' : '0 11px',
  borderRadius: 999,
  background: meta.bg,
  color: meta.fg,
  fontSize: size === 'sm' ? 11.5 : 12.5,
  fontWeight: 600,
  whiteSpace: 'nowrap',
}}>
  <span style={{ width: 6, height: 6, borderRadius: '50%', background: meta.dot, flexShrink: 0 }} />
  {status}
</span>
```

type TipoProduto = 'Produto' | 'Produto Base' | 'Customização'

### Variante 3 — VencidoBadge (orçamento vencido)

Badge especial sem props — apenas indica que o orçamento está vencido.

```tsx
// Sem props — é um indicador fixo
export function VencidoBadge() {
  return (
    <span style={{
      display: 'inline-flex',
      alignItems: 'center',
      gap: 5,
      height: 24,
      padding: '0 9px',
      borderRadius: 999,
      background: '#FCF0EC',
      color: '#C0492B',
      fontSize: 11.5,
      fontWeight: 600,
      whiteSpace: 'nowrap',
    }}>
      <Icons.alertFilled style={{ color: '#C0492B' }} />
      Vencido
    </span>
  )
}
```

### Passo 3 — Verificar cores

- **Rascunho:** fundo bege claro, texto cinza
- **Enviado:** fundo azul claro, texto azul
- **Aprovado:** fundo verde claro, texto verde
- **Em Produção:** fundo laranja claro, texto laranja
- **Pago:** fundo verde escuro claro, texto verde escuro
- **Cancelado:** fundo vermelho claro, texto vermelho
- **Produto Base:** fundo azul claro, texto azul médio
- **Customização:** fundo teal transparente, texto teal

### Passo 4 — Comparar com design

Abrir `design/Pense e Precifique/Orcamentos.html` e `Produtos.html` no browser e comparar as badges — cores e tamanhos devem ser idênticos.

### Passo 5 — Se algo não funcionar

**Cores incorretas:**
Verificar se o STATUS_META está com os valores exatos da tabela acima.

**Erro de TypeScript:**
```bash
npx tsc --noEmit
```
