### Props

```tsx
interface SpinnerProps {
  size?: number           // diâmetro em px (default: 16)
  color?: string          // cor do arco visível (default: '#fff')
  trackColor?: string     // cor do arco de fundo (default: 'rgba(255,255,255,0.45)')
  thickness?: number      // espessura da borda em px (default: 2.4)
}
```

---

### Implementação

```tsx
export default function Spinner({
  size = 16,
  color = '#fff',
  trackColor = 'rgba(255,255,255,0.45)',
  thickness = 2.4,
}: SpinnerProps) {
  return (
    <span
      style={{
        width: size,
        height: size,
        borderRadius: '50%',
        border: `${thickness}px solid ${trackColor}`,
        borderTopColor: color,
        display: 'inline-block',
        animation: 'spin .7s linear infinite',
        flexShrink: 0,
      }}
    />
  )
}
```

---

### Animação — adicionar em `src/index.css`

```css

  to { transform: rotate(360deg); }
}
```

## Como testar

### Passo 1 — Subir o servidor
```bash
npm run dev
```
Abre `http://localhost:5174/dashboard`

---

### Passo 2 — O que você deve ver

```

(fundo laranja)          (teal no branco)
```

### Passo 3 — Verificar animação

Todos os spinners devem girar continuamente — arco completo rotacionando 360° em 0.7s.

1. Clicar em "Simular loading (2,5s)"
2. Botão fica desabilitado com spinner + "Salvando…"
3. Após 2,5s volta ao estado normal

### Passo 5 — Comparar com design

Abrir `design/Pense e Precifique/Login.html` e clicar em "Entrar" — o spinner dentro do botão deve ter exatamente o mesmo visual.

### Passo 6 — Se não girar

Verificar se `@keyframes spin` foi adicionado em `src/index.css`.
