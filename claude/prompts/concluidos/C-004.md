### Variantes

O sistema tem 4 variantes de botão extraídas do design aprovado:

**primary** — ação principal (laranja):
- `background: #F97316`
- `color: #fff`
- `border: none`
- `boxShadow: 0 8px 18px -8px rgba(249,115,22,0.7)`
- Hover: `filter: brightness(1.05)`
- Active (mousedown): `transform: scale(0.97)`

**secondary** — ação secundária (teal):
- `background: #2A9D8F`
- `color: #fff`
- `border: none`
- `boxShadow: 0 8px 18px -8px rgba(42,157,143,0.7)`
- Hover: `filter: brightness(1.05)`
- Active: `transform: scale(0.97)`

**ghost** — ação neutra (outline):
- `background: #fff`
- `color: #5C594F`
- `border: 1.5px solid #EFEDE8`
- Hover: `background: #FAF8F5`

**danger** — ação destrutiva (vermelho suave):
- `background: #FBEDE9`
- `color: #C0492B`
- `border: 1.5px solid rgba(192,73,43,0.4)`
- Hover: `background: #F7E0DA`

---

### Props

```tsx
interface ButtonProps {
  variant?: 'primary' | 'secondary' | 'ghost' | 'danger'
  size?: 'sm' | 'md' | 'lg'
  children: React.ReactNode
  onClick?: () => void
  disabled?: boolean
  type?: 'button' | 'submit' | 'reset'
  fullWidth?: boolean
  icon?: React.ReactNode
  iconRight?: React.ReactNode
  className?: string
}
```

### Tamanhos

| size | height | padding | fontSize |
|------|--------|---------|----------|
| sm   | 36px   | 0 14px  | 13.5px   |
| md   | 46px   | 0 20px  | 14.5px   |
| lg   | 52px   | 0 24px  | 15.5px   |

Default: `md`

---

### Estilos base (todos os botões)

```tsx
borderRadius: 'var(--r-btn)',
fontWeight: 600,
fontFamily: 'inherit',
cursor: 'pointer',
display: 'inline-flex',
alignItems: 'center',
justifyContent: 'center',
gap: 8,
whiteSpace: 'nowrap',
transition: 'filter .15s, transform .12s, background .15s',
flexShrink: 0,
```

**Disabled:** `opacity: 0.5`, `cursor: not-allowed`, sem hover/active

**fullWidth:** `width: 100%`

---

### Implementação

Usar `React.forwardRef` para suportar uso em formulários.

Implementar hover e active via `onMouseEnter`, `onMouseLeave`, `onMouseDown`, `onMouseUp` — não via CSS classes, para manter consistência com o design original.
