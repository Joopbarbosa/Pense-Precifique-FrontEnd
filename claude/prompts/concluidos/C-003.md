# C-003 — TopBar

**Tipo:** componente base  
**Depende de:** C-001 ✅ (Logo + Wordmark), C-002 ✅ (Sidebar)  
**Usado em:** AppLayout — todas as telas autenticadas, apenas no mobile  

---

## Prompt

Cole este prompt no Claude Code:

---

Cria o componente `TopBar` do Pense & Precifique.

**Localização:** `src/components/layout/TopBar.tsx`

---

### Comportamento

- **Mobile (< 768px):** barra fixa no topo com 3 elementos: hamburger | logo+wordmark | sino
- **Desktop (≥ 768px):** completamente oculta — a sidebar já serve como navegação

---

### Props

```tsx
interface TopBarProps {
  onMenuOpen: () => void  // abre o drawer da Sidebar
}
```

---

### Estrutura visual

Barra horizontal com `display flex`, `alignItems center`, `justifyContent space-between`:

**Esquerda — botão hamburger:**
- Fundo transparente, sem borda
- Cor `#3A372F` (dark)
- Padding `4px`
- SVG menu (3 linhas horizontais):
```tsx
const MenuIcon = () => (
  <svg viewBox="0 0 24 24" width="24" height="24" strokeWidth={1.7} fill="none" stroke="currentColor" strokeLinecap="round">
    <path d="M4 7h16M4 12h16M4 17h16"/>
  </svg>
)
```
- `onClick`: chama `onMenuOpen`

**Centro — Logo + Wordmark:**
- `display flex`, `alignItems center`, `gap 8px`
- `<Logo size={26} />`
- `<Wordmark size={14} />`

**Direita — botão sino (notificações):**
- Fundo transparente, sem borda
- Cor `#A29E96` (muted)
- Padding `4px`
- SVG sino:
```tsx
const BellIcon = () => (
  <svg viewBox="0 0 24 24" width="20" height="20" strokeWidth={1.7} fill="none" stroke="currentColor" strokeLinecap="round" strokeLinejoin="round">
    <path d="M6.5 9.5a5.5 5.5 0 0 1 11 0c0 5 2 6 2 6H4.5s2-1 2-6Z"/>
    <path d="M10 19.5a2 2 0 0 0 4 0"/>
  </svg>
)
```
- Por enquanto sem ação (placeholder)

---

### Estilo da barra

```css
.mobile-topbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 10px 16px;
  background: #FFFFFF;
  border-bottom: 1px solid #EFEDE8;
  position: sticky;
  top: 0;
  z-index: 40;
}

@media (min-width: 768px) {
  .mobile-topbar {
    display: none;
  }
}
```

Adicionar esse CSS ao final de `src/index.css`.

---

### Atualizar página de teste em `src/routes/index.tsx`

Substituir o `DashboardPreview` para usar a TopBar no lugar do botão manual:

```tsx
import { useState } from 'react'
import Sidebar from '../components/layout/Sidebar'
import TopBar from '../components/layout/TopBar'

const DashboardPreview = () => {
  const [drawerOpen, setDrawerOpen] = useState(false)
  return (
    <div style={{ display: 'flex', minHeight: '100vh', background: '#FAFAF8' }}>
      <div
        className={`scrim${drawerOpen ? ' show' : ''}`}
        onClick={() => setDrawerOpen(false)}
      />
      <Sidebar
        active="dashboard"
        open={drawerOpen}
        onClose={() => setDrawerOpen(false)}
      />
      <div style={{ flex: 1, display: 'flex', flexDirection: 'column' }}>
        <TopBar onMenuOpen={() => setDrawerOpen(true)} />
        <div style={{ padding: 24 }}>
          <h2 style={{ color: '#3A372F', margin: 0 }}>Dashboard</h2>
          <p style={{ color: '#A29E96' }}>Tela em construção</p>
        </div>
      </div>
    </div>
  )
}
```

## Como testar

### Passo 1 — Subir o servidor
```bash
npm run dev
```
Abre `http://localhost:5174/dashboard`

---

### Passo 2 — Teste desktop (janela normal > 768px)

O que você deve ver:
```
┌─────────────────┬──────────────────────────────┐
│ [logo] Pense&   │  Dashboard                   │
│        Precifiq │  Tela em construção           │
│        Para art │                              │
│                 │                              │
│ ● Dashboard     │  (sem barra no topo)         │
│   Clientes      │                              │
│   ...           │                              │
└─────────────────┴──────────────────────────────┘
```
- **Nenhuma barra no topo** — TopBar deve estar invisível no desktop
- Botão "Abrir menu" antigo não deve mais aparecer

---

### Passo 3 — Teste mobile (375px)

`F12` → ícone celular → iPhone SE (375px)

O que você deve ver:
```
┌──────────────────────────────┐
│ ☰          Pense&Precifique  🔔 │  ← TopBar
├──────────────────────────────┤
│  Dashboard                   │
│  Tela em construção          │
└──────────────────────────────┘
```
- TopBar aparece no topo com fundo branco e borda inferior
- Sidebar some (drawer fechado)

### Passo 4 — Testar abertura do drawer

1. No mobile, clica no ☰ (hamburger)
2. Sidebar desliza da esquerda
3. Overlay escuro aparece
4. Clica no overlay → fecha
5. Clica no X dentro da sidebar → fecha

---

### Passo 5 — Se algo não funcionar

**TopBar aparece no desktop:**
Verificar se `.mobile-topbar` tem `display: none` no breakpoint `min-width: 768px` em `src/index.css`

**Drawer não abre ao clicar no hamburger:**
Verificar se `onMenuOpen` está sendo passado corretamente para o `TopBar` no `DashboardPreview`

**Erro de TypeScript:**
```bash
npx tsc --noEmit
```
