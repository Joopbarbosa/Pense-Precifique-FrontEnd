### Props

```tsx
interface InputProps {
  label?: string
  type?: 'text' | 'email' | 'password' | 'number' | 'tel'
  placeholder?: string
  value: string
  onChange: (value: string) => void
  error?: string
  hint?: string
  icon?: React.ReactNode       // ícone à esquerda
  disabled?: boolean
  required?: boolean
  id?: string
  autoComplete?: string
}
```

### Estrutura visual

```
[label]
┌──────────────────────────────────┐
│ [ícone] placeholder/valor  [👁️] │  ← toggle só no type="password"
└──────────────────────────────────┘
  ⚠ mensagem de erro               ← só quando error preenchido
```

**Label:**
- `fontSize: 13.5px`, `fontWeight: 600`, `color: #5C594F`
- `marginBottom: 7px`

**Container do input:** `position: relative`

**Ícone à esquerda:**
- `position: absolute`, `left: 13px`, `top: 50%`, `transform: translateY(-50%)`
- `color: #A29E96`

**Input:**
- `width: 100%`, `height: 48px`
- `padding: 0 44px 0 40px` (espaço para ícone esquerda + botão direita)
- Sem ícone esquerda: `padding: 0 16px`
- `border: 1.5px solid` variável por estado (ver abaixo)
- `borderRadius: var(--r-input)` — adicionar `--r-input: 10px` em `src/index.css` se não existir
- `fontSize: 15px`, `color: #3A372F`
- `background: #FFFFFF`
- `outline: none`
- `fontFamily: inherit`
- `transition: border-color .15s, box-shadow .15s`

**Estados do input:**

| Estado | Border | Box-shadow | Background |
|--------|--------|------------|------------|
| Padrão | `1.5px solid #EFEDE8` | none | `#FFFFFF` |
| Foco | `1.5px solid #2A9D8F` | `0 0 0 4px rgba(42,157,143,0.12)` | `#FFFFFF` |
| Erro | `1.5px solid #F2B8A6` | none | `#FFFBFA` |
| Disabled | `1.5px solid #EFEDE8` | none | `#F5F4F2` |

**Toggle de senha (type="password"):**
- `position: absolute`, `right: 8px`, `top: 50%`, `transform: translateY(-50%)`
- Botão transparente sem borda, `padding: 6px`, `cursor: pointer`
- Mostra `Icons.eye` quando senha oculta, `Icons.eyeOff` quando visível
- `color: #A29E96`

**Mensagem de erro:**
- `display: flex`, `alignItems: center`, `gap: 5px`
- `marginTop: 6px`, `fontSize: 13px`, `color: #C0492B`
- Ícone `Icons.alertCircle` em `#C0492B` à esquerda

### Passo 3 — Testar foco

1. Clicar no campo E-mail
2. Borda muda para teal `#2A9D8F`
3. Aparece sombra teal suave ao redor
4. Clicar fora → volta à borda cinza

### Passo 4 — Testar toggle de senha

1. Campo Senha mostra bolinhas `••••••`
2. Clicar no ícone 👁 → senha fica visível
3. Clicar novamente → volta a ocultar

### Passo 5 — Testar digitação

1. Digitar no campo E-mail → valor atualiza em tempo real
2. Campo com erro mantém borda vermelha `#F2B8A6` e fundo `#FFFBFA`

### Passo 6 — Comparar com design real

Abrir `design/Pense e Precifique/Login.html` no browser e comparar os campos de e-mail e senha — devem ser visualmente idênticos.

### Passo 7 — Se algo não funcionar

**Border-radius incorreto:**
Verificar se `--r-input: 10px` está em `src/index.css`

**Ícone não aparece:**
Verificar se `Icons.mail` e `Icons.lock` foram adicionados em `Icons.tsx`

**Toggle de senha não funciona:**
O componente precisa de `useState` interno para controlar `showPassword`

**Erro de TypeScript:**
```bash
npx tsc --noEmit
```
