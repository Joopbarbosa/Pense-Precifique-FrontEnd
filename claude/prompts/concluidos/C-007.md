### Props

```tsx
interface ModalShellProps {
  open: boolean
  onClose: () => void
  title: string
  subtitle?: string          // linha menor acima do título
  icon?: React.ReactNode     // ícone no header (quadrado colorido)
  iconBg?: string            // cor de fundo do ícone (default: rgba(249,115,22,0.1))
  iconColor?: string         // cor do ícone (default: #F97316)
  children: React.ReactNode  // conteúdo do body
  footer?: React.ReactNode   // botões de ação no rodapé
  width?: number             // largura máxima (default: 520)
}
```

### Fechar com Escape

Adicionar `useEffect` para fechar ao pressionar `Escape`:

```tsx
useEffect(() => {
  if (!open) return
  const handler = (e: KeyboardEvent) => {
    if (e.key === 'Escape') onClose()
  }
  document.addEventListener('keydown', handler)
  return () => document.removeEventListener('keydown', handler)
}, [open, onClose])
```

## Como testar

### Passo 1 — Subir o servidor
```bash
npm run dev
```
Abre `http://localhost:5174/dashboard`

---

### Passo 2 — O que você deve ver

Dois botões: "Abrir modal com ícone" e "Abrir modal simples"

### Passo 3 — Testar modal com ícone

1. Clicar em "Abrir modal com ícone"
2. Overlay escuro aparece com blur atrás
3. Modal centralizado com animação de escala
4. Header: ícone laranja + "CUSTOMIZAÇÕES" (uppercase cinza) + "Kit Convite Casamento"
5. Botão X no canto direito do header
6. Footer com "Cancelar" (ghost) e "Confirmar" (primary)

### Passo 4 — Testar fechamento

- Clicar no **X** → fecha
- Clicar no **overlay** (fora do modal) → fecha
- Pressionar **Escape** → fecha
- Clicar **dentro** do modal → não fecha

### Passo 5 — Testar modal simples

1. Clicar em "Abrir modal simples"
2. Modal sem ícone, sem subtitle
3. Só título "Confirmar ação" no header
4. Footer com botão "Cancelar orçamento" (danger)

### Passo 6 — Comparar com design

Abrir `design/Pense e Precifique/Criar-Orcamento.html` e acionar um modal — comparar o header, animação e overlay.

### Passo 7 — Se algo não funcionar

**Modal não anima:**
Verificar se `@keyframes fadeIn` e `@keyframes scaleIn` foram adicionados em `src/index.css`

**Clique dentro fecha o modal:**
Verificar se `e.stopPropagation()` está no `onClick` do container interno

**Erro de TypeScript:**
```bash
npx tsc --noEmit
```
