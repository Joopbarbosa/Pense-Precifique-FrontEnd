### Props

```tsx
interface CardProps {
  children: React.ReactNode
  padding?: number | string   // default: 0 (sem padding — conteúdo define o próprio)
  style?: React.CSSProperties
  onClick?: () => void
  hoverable?: boolean         // adiciona efeito hover de elevação
  className?: string
}
```

---

### Estilo base

```tsx
const baseStyle: React.CSSProperties = {
  background: '#fff',
  border: '1px solid #F0EEE9',
  borderRadius: 'var(--r-card)',
  boxShadow: '0 2px 8px rgba(0,0,0,0.05)',
  overflow: 'hidden',
}
```

Adicionar em `src/index.css` se não existir:
```css
:root {
  --r-card: 16px;
}
```

**hoverable:** ao passar o mouse:
```tsx
boxShadow: '0 10px 26px -10px rgba(0,0,0,0.18)'
transform: 'translateY(-3px)'
transition: 'box-shadow .18s, transform .18s'
```

**padding:** quando fornecido, aplica `padding` diretamente no container. Default é `0` — o conteúdo define o próprio padding internamente.

### Subcomponentes

Criar também dois subcomponentes no mesmo arquivo para composição:

**CardHeader**
```tsx
interface CardHeaderProps {
  children: React.ReactNode
  border?: boolean  // borda inferior (default: true)
}
// padding: '16px 20px'
// borderBottom: border ? '1px solid #EFEDE8' : 'none'
```

**CardFooter**
```tsx
interface CardFooterProps {
  children: React.ReactNode
  border?: boolean  // borda superior (default: true)
}
// padding: '16px 20px'
// borderTop: border ? '1px solid #EFEDE8' : 'none'
// display: flex, gap: 11, flexWrap: wrap
```

### Passo 3 — Testar hover

- Card sobe levemente (`translateY(-3px)`)
- Sombra aumenta

### Passo 4 — Comparar com design

Abrir `design/Pense e Precifique/Dashboard.html` — os cards de métricas devem ter o mesmo border-radius, borda e sombra.

### Passo 5 — Se algo não funcionar

**Border-radius incorreto:**
Verificar se `--r-card: 16px` está em `src/index.css`

**Erro de TypeScript:**
```bash
npx tsc --noEmit
```
